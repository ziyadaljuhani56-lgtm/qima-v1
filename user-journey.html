ما يفعله يزور الموقع ويقرأ «كيف تعمل المنصة» يختار «مورد» ويكتب بيانات الجهة والتواصل يدخل بالبريد أو الجوال وكلمة المرور يراجع المؤشرات وآخر طلبات التسعير يحدد نوع الموارد والكمية ويرفق الصور يراجع العروض ويقارنها ويقبل أحدها يتابع حالة النقل حتى وصولها للمصنع يستعرض مركز الأثر ويحمّل التقرير
الصفحة موقع قيمة الرئيسي ✓ انضم للمنصة ✓ تسجيل الدخول ✓ لوحة المورد + رفع طلب جديد + عروض الأسعار ومقارنتها ✓ رحلة الطلب ✓ مركز الأثر وتقرير الاستدامة
دور قيمة عرض القيمة: «كل مورد.. له قيمة» مراجعة الطلب واعتماد الحساب من لوحة الإدارة توثيق الدخول وحماية الحساب عرض حالة الطلبات والإشعارات استقبال الطلب وتقييمه التسعير والتقييم والتسويق وتجميع العروض تنسيق الشريك اللوجستي وصناديق الجمع توثيق العملية وإصدار تقارير الأثر (ESG)
فرصة للتحسين زر واضح «اعرض مواردك واطلب التسعير» توضيح مدة الاعتماد بعد التسجيل الدخول برمز تحقق عبر الجوال (OTP) تنبيه فوري عند وصول عرض جديد اقتراح نوع المورد من الصورة بالذكاء الاصطناعي مرجع سعري عبر «مؤشر قيمة» إشعار عند الاستلام وعند التسليم تقرير جاهز للمشاركة مع أصحاب المصلحة
