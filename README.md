# منصة قيمة (Qima) — المنظومة الرقمية للاقتصاد الدائري وإدارة الموارد ♻️🇸🇦

> **"كل مورد.. له قيمة"**  
> البنية التحتية الرقمية لربط الموردين، مصانع إعادة التدوير، والشركاء اللوجستيين في سوق موحد لتحويل الهدر إلى عائد اقتصادي وأثر بيئي مستدام، تماشياً مع **مبادرة السعودية الخضراء** و**رؤية المملكة 2030**.

---

## 🌟 نظرة عامة على المشروع

منصة **قيمة** هي منصة متكاملة توفر نموذجاً أولياً عملياً (High-Fidelity Interactive Prototype) بمظهر وتصميم نظيف يتماشى مع الهوية البصرية الرسمية للاستدامة في المملكة.

تُمكّن المنصة:
1. **المورّدين (شركات، جهات، فنادق، أفراد):** من عرض الفائض والمخلفات الصناعية والتجارية القابلة للتدوير وطلب تقييم وتسعير فوري.
2. **المشترين ومصانع التدوير:** من استعراض الموارد المتوفرة (كرتون، بلاستيك، معادن، منسوجات، بطاريات، إطارات)، الشراء المباشر أو المزايدة الحية.
3. **الشركاء وأساطيل النقل:** من إدارة المهام اللوجستية وتتبع الشحنات.
4. **فريق الإدارة والتشغيل:** من متابعة مؤشرات الأداء الحية، حجم التداول (GMV)، عمولات الوساطة، ومؤشر الأسعار.

## 🚀 المميزات والصفحات المنجزة

### 1. الصفحة الرئيسية (`index.html`)
- واجهة ترحيبية بهوية الاستدامة مع شريط الميزات ونبذة عن نموذج الاقتصاد الدائري.
- إحصائيات الأثر البيئي وحاسبة التوفير وعوائد التدوير.
- قائمة علوية متجاوبة بالكامل للهواتف والشاشات الكبيرة.

### 2. سوق الموارد الدائرية (`marketplace.html`)
- استعراض الموارد عبر فئات متعددة: كرتون وورق، بلاستيك HDPE وPET، معادن، منسوجات، وغيرها.
- تصنيف بالأسعار، الكميات، مستوى النقاوة، وإمكانية الشراء الفوري أو المزايدة.

### 3. صفحة المزادات الحية (`auction-details.html`)
- كاونتر عد تنازلي حي للمزاد.
- سجل المزايدات اللحظية ونموذج المزايدة السريعة التفاعلية.

### 4. لوحة تحكم المورد (`supplier-dashboard.html`)
- مؤشرات الطلبات النشطة، العوائد، وعروض الأسعار الواردة.
- نافذة منبثقة تفاعلية (Modal) لرفع طلب مورد جديد وإرفاق بيانات الشحنة.

### 5. لوحة الإدارة العامة (`admin-dashboard.html`)
- مؤشرات الأداء الرئيسية: إجمالي التداول (GMV)، الإيرادات، الموردين النشطين.
- مؤشر قيمة الوطني لأسعار الموارد وجدول التحقق من الصفقات والعمليات الجارية.

### 6. رحلة المستخدم (`user-journey.html`)
- مخطط كامل لرحلة المورد ورحلة المشتري عبر 8 مراحل تفصيلية مع مصفوفة التحسين وتجربة المستخدم.

### 7. بوابات المنظومة وتقارير ESG (`portal.html`)
- محاكاة بوابات المورد، مصانع التدوير، إدارة العمليات، وتوليد شهادات الامتثال البيئي ESG بنقرة واحدة.

## 💻 طريقة التشغيل محلياً

1. تأكد من توفر بيئة خادم محلي مثل **XAMPP** أو خادم ويب خفيف.
2. ضع مجلد المشروع داخل مسار خادم الويب:
   ```bash
   C:\xampp\htdocs\qima-v1
   ```
3. افتح المتصفح وتوجه إلى:
   ```text
   http://localhost/qima-v1/index.html
   ```
   أو قم بفتح ملف `index.html` مباشرة في أي متصفح حديث.

## 🛠 التقنيات المستخدمة
- **HTML5 & Semantic Markup** لبناء هيكل نقي وسهل القراءة.
